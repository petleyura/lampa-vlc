# Changelog

Усі помітні зміни проєкту. Формат — стислий, без вигаданих версій і дат.

## v0.6.0 — 2026-11-02

### Додано

- українська Debug Panel: підписи, стани, джерела, журнал подій і повідомлення про помилки;
- кнопка **«Аудіодоріжка»** та список доступних аудіодоріжок;
- реальне перемикання аудіодоріжки в Tizen AVPlay через `setSelectTrack`;
- перемикання в HTML5, якщо браузер реалізує `HTMLMediaElement.audioTracks`;
- збереження поточної позиції після перемикання доріжки;
- пояснення, якщо рушій не надає список доріжок або перемикання неможливе.

### Змінено

- `Html5Engine.audioTracks()` тепер розрізняє відсутність API (`null`) і порожній список (`[]`);
- `TizenAvplayEngine` читає `fourCC`, канали та частоту дискретизації з `extra_info`;
- активна доріжка AVPlay визначається через `getCurrentStreamInfo`, якщо API доступне;
- версія плагіна — `0.6.0`.

### Діагностика (Етап 6.2)

- додано **ШВИДКІСТЬ ЗАВАНТАЖЕННЯ**: фактичні `transferSize` з Resource Timing або явно позначена оцінка за приростом буфера;
- додано **ФОРМАТ ВІДЕО**: контейнер/кодек/FPS/роздільність із `data.ffprobe` або API рушія, без здогаду за URL;
- додано **АУДІОДОРІЖКИ** у Debug Panel;
- додано ізольований PoC Mediabunny/AC-3 поза репозиторієм; у основний плеєр залежність не інтегрована.

### Обмеження

- у Chromium `HTMLMediaElement.audioTracks` зазвичай відсутній, тому HTML5-перемикання там недоступне;
- AC-3/E-AC-3/DTS не декодуються HTML5-рушієм; на Tizen їх підтримка залежить від AVPlay і моделі TV;
- власного клієнтського декодера AC-3/E-AC-3 у цій версії немає;
- UI субтитрів, HLS/DASH та IPTV-перехоплення не реалізовані.

## Етап 6.3 — діагностика torrent-аудіо (без зміни версії)

- додано отримання фактичних метаданих TorrServer через `/ffp/{hash}/{id}` (контейнер, кодек, FPS, аудіодоріжки);
- кнопка аудіодоріжок отримала видимий підпис **«АУДІО»**;
- якщо HTML5 не надає `audioTracks`, панель показує метадані доріжок із TorrServer, але не імітує перемикання;
- експериментально підтверджено: Chrome відтворює MKV-відео без звуку, не повертає `audioTracks` і не повідомляє `MediaError` для AC-3/E-AC-3;
- AC-3/E-AC-3 у HTML5 залишаються непідтримуваними без окремого декодера.

## v0.5.0 — 2026-11-01

### Додано

- `TizenAvplayEngine` для Samsung Tizen через `webapis.avplay`.
- Автоматичний fallback AVPlay → HTML5 у разі фатальної помилки.
- `ENGINE_CONTRACT` і `EngineFactory` як єдиний інтерфейс рушіїв.
- Пункт плеєра в налаштуваннях Lampa: `player`, `player_torrent`, `player_iptv`.
- Debug Panel із метриками рушія та журналом подій.

### Змінено

- Player Core працює лише через контракт рушія, без прямого доступу до `<video>`/AVPlay.
- Вибір рушія на Tizen: `Platform.is('tizen')` + наявність `webapis.avplay`.

### Обмеження

- Немає UI вибору аудіодоріжок і субтитрів.
- IPTV-пункт є, але перехоплення IPTV не реалізовано.
- HLS/DASH не підтримуються.
- MKV/HEVC/AC-3/DTS залежать від браузера або TV.
- Реальні пристрої Tizen/webOS/Android TV не тестувалися.
